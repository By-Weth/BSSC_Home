System Architecture
BSSC requires a 64-bit x86_64 (AMD64) architecture. ARM and 32-bit systems are not supported.

System Requirements

Hardware

  • Minimum 4GB RAM
  • 2GB free disk space
  • x86_64 processor
  • Network connectivity

Software

  • Node.js v20.x LTS
  • Python 3.10+
  • PM2 Process Manager
  • System libraries

Network

  • Internet connection
  • Local network access
  • Ports 3000, 3001
  • Firewall configured

Installation Guide

Follow these steps carefully to ensure a successful installation

1 Install Node.js v20.x LTS

Node.js is required to run the BSSC backend. Install the latest LTS version:

bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - sudo apt install -y nodejs node --version npm --version
Verification
The commands above should display v20.x.x for Node.js and 10.x.x for npm.

2 Install System Libraries

Install the required libraries for Chromium (used internally by Electron):

bash
sudo apt update sudo apt install -y ca-certificates fonts-liberation libasound2 libatk-bridge2.0-0 libatk1.0-0 libatspi2.0-0 libcups2 libdbus-1-3 libdrm2 libgbm1 libgtk-3-0 libnspr4 libnss3 libwayland-client0 libxcomposite1 libxdamage1 libxfixes3 libxkbcommon0 libxrandr2 xdg-utils libu2f-udev libvulkan1

3 Install Python Dependencies

BSSC uses Python for synchronization services with ZKTeco biometric devices:

bash
sudo apt install -y python3-pip python3-pycryptodome python3-flask python3-requests pip install pyzk --break-system-packages
Note
The --break-system-packages flag is required on Ubuntu 23.04+ to install Python packages globally.

4 Install PM2 Process Manager

PM2 manages backend processes and ensures the system restarts automatically after boot:

bash
sudo npm install -g pm2 pm2 startup systemd sudo env PATH=$PATH:/usr/bin /usr/lib/node_modules/pm2/bin/pm2 startup systemd -u $USER --hp $HOME pm2 --version
Important
Execute the command shown by PM2 after pm2 startup systemd to enable autostart.

5 Install BSSC Package

Attention
Contact the BSSC team to obtain the bssc-app_1.0.0_amd64.deb installation file before proceeding.

Installing the .deb Package

bash
cd ~/Downloads sudo dpkg -i bssc-app_1.0.0_amd64.deb sudo apt install -f

Verifying Installation

bash
ls -la /opt/BSSC/ which bssc bssc --version
Installation Structure
  • /opt/BSSC/bssc - Main executable
  • /opt/BSSC/resources/app/ - Electron application
  • /opt/BSSC/resources/backend/ - NestJS API
  • /opt/BSSC/resources/python-service/ - Python services
  • /opt/BSSC/chrome-sandbox - Chromium sandbox

6 MANDATORY Sandbox Configuration

CRITICAL STEP - REQUIRED
You MUST execute the commands below BEFORE starting the application for the first time. Otherwise, BSSC will not start and will display the error shown below.

Error You Will See if You Skip This Step

FATAL: setuid_sandbox_host.cc(158)] The SUID sandbox helper binary was found, but is not configured correctly. Rather than run without sandboxing I'm aborting now.

Solution (EXECUTE NOW)

bash
sudo chown root:root /opt/BSSC/chrome-sandbox sudo chmod 4755 /opt/BSSC/chrome-sandbox ls -la /opt/BSSC/chrome-sandbox
Correct Permissions Verification

The last command should display:

-rwsr-xr-x 1 root root [size] [date] /opt/BSSC/chrome-sandbox

The 's' in place of 'x' (rwsr-xr-x) indicates that the SUID bit is correctly activated.

Important
This step is necessary every time you reinstall or update BSSC. Permissions must be reconfigured after each installation.

7 Starting the System

Start Main Application

bash
bssc

Or run directly:

bash
/opt/BSSC/bssc

Verify Python Services Status

bash
sudo systemctl status bssc-logs sudo systemctl status bssc-users sudo journalctl -u bssc-logs -f sudo journalctl -u bssc-users -f
Service Description Port
bssc-logs Collects logs from biometric devices N/A
bssc-users Synchronizes users between devices N/A
NestJS Backend Main system API 3001

8 Complete Installation Verification

Validation Checklist

  • Node.js v20.x installed and working
  • Python 3.10+ installed with all dependencies
  • PM2 installed and configured for autostart
  • BSSC package installed in /opt/BSSC/
  • Sandbox permissions configured (-rwsr-xr-x root:root)
  • bssc-logs service active and running
  • bssc-users service active and running
  • Main application starting without errors

Automated Verification Script

bash
echo "=== BSSC Verification ===" echo "" echo "Node.js: $(node --version)" echo "NPM: $(npm --version)" echo "Python: $(python3 --version)" echo "PM2: $(pm2 --version)" echo "" echo "Services:" systemctl is-active bssc-logs && echo "✓ bssc-logs: ACTIVE" || echo "✗ bssc-logs: INACTIVE" systemctl is-active bssc-users && echo "✓ bssc-users: ACTIVE" || echo "✗ bssc-users: INACTIVE" echo "" echo "Sandbox permissions:" ls -l /opt/BSSC/chrome-sandbox | grep "rwsr-xr-x.*root root" && echo "✓ Sandbox: OK" || echo "✗ Sandbox: INCORRECT"

Troubleshooting

Common issues and their solutions

Command bssc not found

bash
hash -r ls -la /usr/local/bin/bssc sudo ln -sf /opt/BSSC/bssc /usr/local/bin/bssc

Python services do not start

bash
sudo journalctl -u bssc-logs -n 100 --no-pager sudo journalctl -u bssc-users -n 100 --no-pager python3 -c "from Crypto.Cipher import AES; print('pycryptodome: OK')" python3 -c "import flask; print('flask: OK')" python3 -c "import zk; print('pyzk: OK')" sudo apt install --reinstall python3-pycryptodome python3-flask sudo systemctl daemon-reload sudo systemctl restart bssc-logs bssc-users

One service works but the other doesn't

Tip
The services are independent. If one fails, the other continues working.
  • bssc-logs: Check if paths exist in /opt/BSSC/resources/python-service/logs-collector/
  • bssc-users: Check if paths exist in /opt/BSSC/resources/python-service/users-sync/

Application does not connect to ZKTeco device

  • Verify the device is powered on and on the same network
  • Test connectivity: ping DEVICE_IP
  • Check firewall: sudo ufw status
  • Confirm correct IP and port in BSSC settings
  • Check Python service logs for connection errors

Chrome sandbox error persists

bash
ls -la /opt/BSSC/chrome-sandbox sudo chown root:root /opt/BSSC/chrome-sandbox sudo chmod 4755 /opt/BSSC/chrome-sandbox ls -la /opt/BSSC/chrome-sandbox
If error persists
Ensure the file shows -rwsr-xr-x 1 root root. The 's' must be present.

IMPORTANT

bash
sudo chown root:root /opt/BSSC/chrome-sandbox sudo chmod 4755 /opt/BSSC/chrome-sandbox
Update Note
During the update, both services are automatically stopped and reconfigured. Your settings and data are preserved in ~/.config/BSSC/.
