Sistemas Operacionais Suportados

O BSSC foi testado e é totalmente compatível com as seguintes distribuições Linux

Ubuntu

22.04 LTS / 24.04 LTS

Debian

11+ (Bullseye)

Linux Mint

21+ (Vanessa)

Arquitetura do Sistema
O BSSC requer arquitetura 64-bit x86_64 (AMD64). Sistemas ARM e 32-bit não são suportados.

Requisitos do Sistema

Hardware Mínimo

  • Mínimo 4GB RAM
  • 2GB de espaço livre em disco
  • Processador x86_64
  • Conectividade de rede

Software

  • Node.js v20.x LTS
  • Python 3.10+
  • PM2 Process Manager
  • System libraries

Network

  • Internet connection
  • Local network access
  • Ports 3000, 3001
  • Firewall configured

Guia de Instalação

Siga estes passos cuidadosamente para garantir uma instalação bem-sucedida

1 Atualizar Pacotes do Sistema

Primeiro, certifique-se de que seu sistema está atualizado:

bash
sudo apt update sudo apt upgrade -y

2 Instalar Dependências Python

BSSC uses Python for synchronization services with ZKTeco biometric devices:

bash
sudo apt install -y python3-pip python3-pycryptodome python3-flask python3-requests pip install pyzk --break-system-packages
Note
The --break-system-packages flag is required on Ubuntu 23.04+ to install Python packages globally.

3 Instalar Pacote BSSC

Attention
Contact the BSSC team to obtain the bssc-app_1.0.0_amd64.deb installation file before proceeding.

Installing the .deb Package

bash
cd ~/Downloads sudo dpkg -i bssc-app_1.0.0_amd64.deb sudo apt install -f

Verifying Installation

bash
ls -la /opt/BSSC/ which bssc bssc --version
Installation Structure
  • /opt/BSSC/bssc - Main executable
  • /opt/BSSC/resources/app/ - Electron application
  • /opt/BSSC/resources/backend/ - NestJS API
  • /opt/BSSC/resources/python-service/ - Python services
  • /opt/BSSC/chrome-sandbox - Chromium sandbox

4 Configuração OBRIGATÓRIA do Sandbox

CRÍTICO - Execute Antes da Primeira Inicialização
Você DEVE executar estes comandos antes de iniciar o BSSC pela primeira vez. Se ignorado, a aplicação não iniciará.
bash
sudo chown root:root /opt/BSSC/chrome-sandbox sudo chmod 4755 /opt/BSSC/chrome-sandbox
Verificar Permissões
Run ls -la /opt/BSSC/chrome-sandbox and confirm it shows -rwsr-xr-x 1 root root. The 's' is essential.

5 Iniciando o Sistema

Start Main Application

bash
bssc

Or run directly:

bash
/opt/BSSC/bssc

Verify Python Services Status

bash
sudo systemctl status bssc-logs sudo systemctl status bssc-users sudo journalctl -u bssc-logs -f sudo journalctl -u bssc-users -f
Service Description Port
bssc-logs Collects logs from biometric devices N/A
bssc-users Synchronizes users between devices N/A
NestJS Backend Main system API 3001

6 Verificação Completa da Instalação

Validation Checklist

  • System packages updated
  • Python 3.10+ installed with all dependencies
  • BSSC package installed in /opt/BSSC/
  • Sandbox permissions configured (-rwsr-xr-x root:root)
  • bssc-logs service active and running
  • bssc-users service active and running
  • Main application starting without errors

Resolução de Problemas

Problemas comuns e suas soluções

Command 'bssc' not found

bash
sudo ln -sf /opt/BSSC/bssc /usr/local/bin/bssc

Serviços não iniciam

bash
# Check logs sudo journalctl -u bssc-logs -n 50 sudo journalctl -u bssc-users -n 50 # Restart services sudo systemctl restart bssc-logs bssc-users

Erro de Sandbox

bash
sudo chown root:root /opt/BSSC/chrome-sandbox sudo chmod 4755 /opt/BSSC/chrome-sandbox

Não consegue conectar ao dispositivo ZKTeco

  • Verifique se o dispositivo está ligado e na mesma rede
  • Test: ping DEVICE_IP
  • Verificar firewall: sudo ufw status
  • Confirme IP e porta corretos nas configurações do BSSC

After receiving the new .deb package:

bash
sudo dpkg -i bssc-app_X.Y.Z_amd64.deb sudo systemctl restart bssc-logs bssc-users systemctl status bssc-logs bssc-users
IMPORTANT

After each update, you MUST reconfigure sandbox permissions:

bash
sudo chown root:root /opt/BSSC/chrome-sandbox sudo chmod 4755 /opt/BSSC/chrome-sandbox
Update Note
During the update, both services are automatically stopped and reconfigured. Your settings and data are preserved in ~/.config/BSSC/.
